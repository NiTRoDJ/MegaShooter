❓ Синтаксис розширеного режиму

Пиши команди схоже на Python. Один рядок — одна команда. Рядки з # — коментарі.

Нагорода за хвилю

reward = 200
reward(wave:3) = 500
  • reward = N — токени за кожну хвилю
  • reward(wave:W) = N — нагорода лише за хвилю W
  • Максимум 500 токенів на одну хвилю
  • Якщо більше — під час тесту: Count Error: The Reward is too high

Вставити боса

spawnboss(wave:2, num:1)
spawnboss(wave:3, num:1, num:2)
  • wave — номер хвилі (1, 2, 3...)
  • num — номер боса (зараз 1–7)
  • Два боси одразу: spawnboss(wave:3, num:1, num:2)
  • Власного боса задай командами customboss + attack

Власний бос

customboss(wave:2, visual:1, hp:2000, name:"Guard")
attack(chance:40, type:0, c:5, d:7)
attack(chance:30, type:1, c:2, d:30)
attack(chance:20, type:2, c:3, t:0)
attack(chance:10, type:3, c:1)
  • visual / vialuse — вигляд боса 1–7
  • type: 0 кулі, 1 гігантські кулі, 2 монстри, 3 кулі смерті
  • для type 2: t=0 стрілун, t=1 золотий
  • можна писати блок custom("BOSSES"):{ ... }

Діалог перед хвилею

dialog(wave:1, "Обережно, бос!", 3)
  • Перший аргумент після wave — текст у лапках
  • Останнє число — час у секундах
